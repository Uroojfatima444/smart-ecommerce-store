# 🏡 HomeHaven – Furniture & Decor Store

A responsive e-commerce front-end built with HTML, CSS, Bootstrap and vanilla JavaScript.

**🔗 Live Demo:** https://YOUR-USERNAME.github.io/REPO-NAME/

![HomeHaven home page](screenshots/home.png)

## Features
- Product listing with category filters and live search (both work together)
- Shopping cart with add, remove and quantity controls, plus a running total
- Cart saved in localStorage, so it survives a page refresh
- Product details popup
- Wishlist heart toggle
- Dark mode
- Demo checkout form (Cash on Delivery, no real payment)

## Tech Stack
HTML5 · CSS3 · Bootstrap 5 · JavaScript (ES6)

## Run Locally
1. Clone the repo:
   `git clone https://github.com/YOUR-USERNAME/REPO-NAME.git`
2. Open `index.html` in your browser. No installation needed.
